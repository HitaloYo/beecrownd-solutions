# Soluções do Beecrowd

Minhas soluções para problemas iniciantes do [Beecrowd](https://judge.beecrowd.com/) (antigo URI Online Judge), em Java e Python.

## Python

`python/Beecrownd.py` reúne 24 problemas, cada um em uma função com o número do problema (por exemplo, `b1007()` resolve o 1007). Para rodar um deles, chame a função e digite a entrada no terminal.

## Java

Uma classe por problema em `java/`:

| Arquivo | Problema |
| --- | --- |
| `HelloWorld.java` | 1000 · Hello World |
| `ExtremamenteBasico.java` | 1001 · Extremamente Básico |
| `AreaDoCirculo.java` | 1002 · Área do Círculo |
| `SomaBasica.java` | 1003 · Soma Simples |
| `ProdutoSimples.java` | 1004 · Produto Simples |
| `MediaUm.java` | 1005 · Média 1 |
| `MediaDois.java` | 1006 · Média 2 |
| `Diferenca.java` | 1007 · Diferença |
| `Salario.java` | 1008 · Salário |

```bash
cd java
javac Diferenca.java && java Diferenca
```
